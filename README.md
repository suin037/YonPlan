# 연플랜 (YonPlan)

연세대학교 신촌캠퍼스 학생을 위한 졸업요건 · 학사 로드맵 관리 앱이에요.
UXIM 학회 3조 프로젝트입니다.

## 화면

- **홈**: 전체 이수율, 졸업요건 이수율, 놓치기 쉬운 항목, 이번 학기 시간표 요약
- **졸업요건** (홈의 "남은 졸업요건 보기"로 진입): 전공·교양·공통 조건별 이수 현황과 남은 과목
- **로드맵**: 학기별 이수·수강 중·계획·추천 과목
- **내 정보**: 학적 설정(입학 연도, 학년, 본전공, 추가 이수과정, 목표 졸업 학기), 이수 내역 관리
- **이수 과목 등록**: 런어스 '과거강좌조회' 캡처를 올리면 학수번호를 읽어 학기별로 등록해요. 2026-2 과목은 수강 중으로 들어가요. 캡처 방법은 단계별 안내 화면에서 보여 줘요.

- 처음 방문하면 **처음부터 시작하기**(내 학적·이수 과목 직접 입력)와 **예시 데이터로 체험하기**(24학번 경제학 + 심리학 복수전공) 중에서 골라요.
- 로그인 없이 이 브라우저(localStorage)에만 저장해요. 내 정보와 체험 데이터는 따로 저장돼요.
- 졸업요건은 경제학 · 응용통계학 · 심리학 2020~2026학번을 계산해요. 다른 학과는 학적은 저장되고 요건은 '준비 중'으로 보여요.
- 캡처 읽기는 Tesseract.js(무료 오픈소스 OCR)로 브라우저 안에서 해요. 사진은 서버로 보내지 않아요.
  인식 엔진과 영어 모델은 `npm run build` 전에 `scripts/copy_ocr.mjs`가 `public/ocr/`로 복사해서 사이트와 함께 배포돼요(저장소에는 올리지 않아요).
  한국어 과목명은 인식이 불안정해서 학수번호(예: ABC1234.01-00)만 읽고, 과목명·학점은 앱 데이터에서 찾아요.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173/YonPlan/
npm run build    # dist/ 에 배포용 파일 생성
```

## 구조

```
index.html          앱 뼈대 (폰 프레임, 하단 탭, UT 패널)
src/style.css       스타일 · 색상 토큰
src/data.js         고정 목록(학과 등)과 public/data/*.json 불러오기
src/model.js        졸업요건 고르기·영역별 학점 계산, 학기 목록
src/demo.js         체험하기 예시 학생 데이터
src/ocr.js          캡처에서 학수번호·연도·학기 읽기 (Tesseract.js)
src/main.js         상태·저장, 화면 렌더링, 이벤트 처리
public/data/        앱 데이터(JSON). scripts/build_data.py로 만들어요
public/favicon.svg  아이콘
```

## 데이터 다시 만들기

dataset 폴더(CSV 13개)가 바뀌면 아래를 실행하고 커밋해요.

```bash
python3 scripts/build_data.py "C:/Users/SUIN/OneDrive/바탕 화면/학회/dataset"
```

## 색상

- 기본은 흰 배경과 검정·회색(무채색)이에요.
- 강조는 연세블루(`#003876`) 한 가지만 써요.
- 상태는 색만으로 구분하지 않고 아이콘과 글자를 함께 써요.

| 상태 | 표시 |
| --- | --- |
| 이수 | ✓ 회색 |
| 수강 중 | ● 연세블루 채움 |
| 계획 | ◆ 연세블루 테두리·연한 배경 |
| 추천 | ☆ 회색 테두리 |
| 충돌·부족 | ! 검정 |
