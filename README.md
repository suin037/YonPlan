# 연플랜 (YonPlan)

연세대학교 신촌캠퍼스 학생을 위한 졸업요건 · 학사 로드맵 · 시간표 플래너예요.
UXIM 학회 3조 프로젝트입니다.

## 화면

- **홈**: 전체 이수율, 졸업요건 이수율, 놓치기 쉬운 항목, 이번 학기 시간표 요약
- **졸업요건**: 전공·교양·공통 조건별 이수 현황과 남은 과목
- **로드맵**: 학기별 이수·수강 중·계획·추천 과목
- **시간표**: 시간표 1안/2안, 시간 충돌 확인과 대안 찾기
- **내 정보**: 학적 설정(입학 연도, 학년, 본전공, 추가 이수과정, 목표 졸업 학기), 이수 내역 관리

과목·분반·이수 내역은 현재 예시 데이터(24학번 경제학 + 심리학 복수전공)예요.
학적 입력은 신촌캠퍼스 학부 전공 전체를 고를 수 있어요.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173/YonPlan/
npm run build    # dist/ 에 배포용 파일 생성
```

## 구조

```
index.html          앱 뼈대 (폰 프레임, 하단 탭, UT 패널)
src/style.css       스타일 · 색상 토큰
src/data.js         예시 과목·분반·학기 데이터, 학과 목록
src/main.js         상태, 화면 렌더링, 이벤트 처리
public/favicon.svg  아이콘
```

## 색상

배경은 흰색이고, 그 밖의 색은 모두 로열블루(`#4169e1`)의 진하기 단계로만 써요 (다크 모드 없음).
글자는 가장 진한 남색, 테두리·회색 역할은 연한 블루가 맡아요.
상태는 진하기 차이로 구분하고, 색만으로 구분하지 않도록 아이콘과 글자를 함께 써요.

| 상태 | 표시 |
| --- | --- |
| 이수 | ✓ 진한 블루 |
| 수강 중 | ● 로열블루 |
| 계획 | ◆ 연한 블루 |
| 추천 | ☆ 가장 연한 블루 |
| 충돌·부족 | ! 남색 |
